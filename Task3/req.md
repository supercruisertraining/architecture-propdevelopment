# Требования к безопасности

- Использование шифрованного соединения при передаче данных
- Шифрованное хранение биометрических данных и номеров авто
- Регистрация событий в системе

# Протоколы аутентификации и авторизации
### Аутентификация пользователя
OAuth 2.0 + OpenID Connect
Мобильное приложение аутентифицирует клиента в системе PropDevelopment

### Авторизация действий пользователя
OAuth2 + ABAC
Пользователь имеет доступ только к конкретным девайсам

# Организация взаимодействия между системами

- В стороннюю систему передаются обезличенные зашифрованные биометрические данные, 
имеющие токен в качестве идентификатора
- В стороннюю систему не передаются данные о владельцах автомобилей
- Оператор ПД регистрируется в Роскомнадзор
